# docs/registry/ — Proyección del catálogo de prompts y skills

**Autoridad lógica:** frontmatter + layout vivo en disco + `scripts/discover_skills.py`.
Decisión vinculante: [`docs/decisions/DEC-008B-001-registry-model.md`](../decisions/DEC-008B-001-registry-model.md)
adopta *Discovery recursivo sin manifest*.

**NO existe `registry.json` ni ningún manifest autoritativo aquí.** Introducir una
segunda fuente de verdad fue evaluado y rechazado en DEC-008B-001 (viola CEM v0:
"un registry incorrecto es peor que no tener").

## Artefactos

- `INDEX.md` — **proyección generada** del catálogo derivado. NO editar a mano.
  Lleva un marcador `AUTOGENERATED` en su primera línea. Se regenera con:

  ```bash
  python scripts/discover_skills.py --generate-index
  ```

## Catálogo derivado (WOT-2026-008c)

`discover_skills.py` deriva, desde frontmatter y layout vivos, un catálogo
enriquecido. Cada entrada declara:

| campo | derivación |
|-------|-----------|
| `kind` | layout: `skill` / `prompt` / `reference` / `shared` / `script-consumer` |
| `path` | ruta relativa al motor |
| `status` | frontmatter `status:`; default `active`; soporta `active`/`deprecated`/`draft` |
| `owner` | frontmatter `author`, fallback `role`, default `system` |
| `canonical_source` | == `path` (008c no renombra) |
| `aliases` | frontmatter `triggers` (los triggers son los alias de invocación) |

Comandos:

```bash
python scripts/discover_skills.py --catalog        # JSON del catálogo derivado
python scripts/discover_skills.py --generate-index # regenera INDEX.md
python scripts/discover_skills.py --check-index     # stale gate (exit 1 si diverge)
```

## Efecto real de `status`

El `trigger_map` de `discover_skills()` solo enlaza skills `active`. Las skills
`deprecated` o `draft` siguen en el catálogo (visibles, auditables) pero **no
despachan triggers**. La metadata tiene efecto real, no es solo presencia en disco.
